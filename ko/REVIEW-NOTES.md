# 한국판 검토 기록

## 2026-09-30 · 첫 초안과 공개 미리보기

원문 34장 641개 항목을 식별자로 정리했다. 현재 한국판 6개 장의 28개 항목은 선별해서 재구성한 초안이다. 원문 전체를 순서대로 번역한 결과가 아니다. 아직 모든 원문 항목의 대조 상태는 `pending`이며 원문의 수치·출처·예외를 빠짐없이 검토해야 한다.

### 응급상황 안내에서 바꾼 점

- 원문 13장 1번의 중국 신고번호를 한국의 119로 바꾸고, 신고와 가슴압박 순서를 질병관리청 안내로 다시 작성했다. 자동심장충격기 사용은 별도 카드로 나눴다.
- 중국 심장정지 등록사업의 통계를 한국 통계로 표시하지 않았다. 한국판 초기 행동 안내에는 생존율 수치를 넣지 않았으며 원문의 연구 결과·증거 등급은 중국어 파일에 보존했다.
- 원문 13장 3번의 ‘4.5시간을 넘기면 사실상 무의미하다’는 단정은 사용하지 않았다. 응급 치료 가능성은 병원에서 판단하도록 작성했다. 시간별 치료 효과를 다루는 별도 문헌 대조는 아직 끝나지 않았다.
- 원문 13장 4번에 있는 눈을 감고 서 보기 등 자가 동작 검사를 응급 신고의 선행 조건으로 두지 않았다. 갑작스러운 증상이 있으면 119에 연락하도록 안내했다.
- 원문 13장 7번의 ‘15분 이상’ 문구가 신고를 미루는 기준으로 읽힐 수 있어, 한국 질병관리청의 즉시 신고 안내를 따랐다.
- 중국 민법의 응급구조 면책 조항을 한국의 무조건적인 면책으로 번역하지 않았다. 한국법 검토가 끝나기 전에는 면책을 보장하지 않는다.

국내 안내 출처는 각 항목에 기재했다. 기관의 그림을 복사하거나 수정하지 않고, 공식 자료의 사실관계에 근거해 한국어 행동 안내를 새로 작성했다.

### 이미지와 화면

- 한국판 `og.png`: 1200×630. `ko/cover.html`에서 만든 새 표지로 교체하고 실제 PNG의 한글과 잘림을 확인했다.
- 원작 광고·위챗 후원 이미지는 한국판 HTML과 배포 파일에 포함하지 않는다. 원본은 저장소에 보존한다.
- 한국판 검색, 검색 결과 없음, 장 선택, 초기화, 필터 밖 항목의 고정 링크 열기를 실제 Chrome에서 확인했다.
- 화면 너비 1440px, 390px, 320px에서 가로 넘침이 없었고 실행 중 JavaScript 오류가 없었다. 데스크톱·모바일 캡처도 확인했다.
- 자동 검사는 본문 필드, 원문 항목 누락, 링크 대상, HTML 문자 처리와 광고 제외를 확인한다. 내용의 의학적·법적 검수 완료를 뜻하지 않는다.

### 다음 대조 작업

각 원문 항목의 수치·예외·근거를 읽고 한국판 항목 연결과 유지·대체·통합·제외 사유를 기록한다. 제목만 비슷하다고 검토 완료로 바꾸지 않는다. 정책의 출처 날짜와 현재 적용 여부가 다른 항목, 보험·산재·세제 상세 검토 대기 항목을 먼저 보완한다.
